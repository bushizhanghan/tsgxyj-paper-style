# 引文基准与来源画像（Citation Benchmarks）

> **本文件由 `scripts/citation_analysis.py --corpus-stats` 从 118 篇刊文的 5115 条参考文献挖掘生成，2026-10 更新。**
> 用途：投稿前自查「文献够不够新、来源够不够好、类型结构合不合理」——这是审稿意见里出现频率最高的技术性退修理由之一。
> 用法：`python scripts/citation_analysis.py 你的论文.docx`（自动对照本基准给风险提示）。

---

## 0. 基准来源

- 样本：118 篇刊文中可解析出参考文献的 **111 篇**，共 **5115 条**文献
- 篇均 **46.1 条**
- 解析方法：全角转半角归一化后按 `[n]` 切分，正则提取类型标识 / 出版年 / 来源

---

## 1. 时效性基准（该刊有多"新"）

| 指标 | 该刊实测 |
|---|---|
| 篇内引文年份中位（各篇中位再取中位） | **2022** |
| 近 5 年（2021+）文献占比 | **中位 67.4%**｜P25 **53.8%**｜均值 66.0% |
| 年份覆盖 | 多为近 10 年为主干，少量经典文献追溯 |

**自查口径**：
- 近 5 年占比 **≥ 67%** → 时效性达标
- **54%–67%** → 区间内，可再补 2–3 篇新文献
- **< 54%（P25）** → 审稿人极易提「文献陈旧」，必须补新文献

## 2. 文献类型结构基准

| 类型 | 该刊占比 | 条数 | 说明 |
|---|---|---|---|
| **J 期刊论文** | **68.0%** | 3476 | 绝对主体 |
| 无类型标识 | 14.8% | 755 | 多为早期著录不规范，**你的稿应补全标识** |
| **EB/OL 网络资源** | **8.6%** | 441 | 政策文件、机构报告、标准在线版 |
| M 专著 | 3.8% | 196 | |
| C 会议论文 | 1.6% | 82 | 少 |
| D 学位论文 | 1.4% | 74 | 少 |
| J/OL 网络期刊 | 1.0% | 52 | |
| N 报纸 | 0.5% | 28 | 极少数政策评论 |
| R 报告 / S 标准 | 0.1% / 0.1% | 7 / 3 | **极为罕见** |

**自查口径**：
- 期刊论文应占 **六成以上**
- 会议论文（C）、学位论文（D）超过 3 条即偏高
- **S 标准类**该刊几乎不引（0.1%），但**在无障碍/技术规范类选题中属必要文献，属合理使用**——不必强删，但应控制在支撑规范要求的必要数量
- 一条文献都无 EB/OL 时，可考虑用政策文件/标准在线版补时效性

**投稿含义**：

- 若你的来源集中在非图情类刊物（如计算机、教育技术），审稿人可能质疑"刊情不符"

## 4. 与 `ref_format.md` / `verify_refs.py` 的分工

| 工具/文件 | 查什么 |
|---|---|
| `ref_format.py` | 单条文献的 **GB/T 7714 要素**是否完整（作者/年/类型/卷期/页码） |
| `verify_refs.py` | 正文引用与文献表的**对应关系**（缺号/重号/幽灵引用） |
| **`citation_analysis.py`（本文件）** | 整体**时效性 / 类型结构 / 来源集中度**是否符合该刊习惯 |

三者是三个层次：单条格式 → 表内一致 → 整体画像。
