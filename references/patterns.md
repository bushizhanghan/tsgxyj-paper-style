# 原文写作模式库（Patterns）

> **本文件由 `scripts/analyze_corpus.py` 从 118 篇原文（4743 段正文 + 117 篇摘要）挖掘生成，2026-10 更新。**
> 所有句式与比例均来自该刊真实文本，非归纳想象。写某段前先查本文件：「该刊这类段怎么写」。
> 重新生成：`python scripts/analyze_corpus.py --json`（会同时写语料库 `patterns.json`）。

## 0. 使用方式

- **模式 C 新写**：按节查对应句式族，取骨架套自己的内容；不要照抄例句文字。
- **模式 B 改写**：若稿件句式为「该刊罕见形态」，按本文件主流形态调。
- **模式 A 诊断**：本文件是「位置→问题→依据」中「依据」的原文出处。

## 3. 引用句式（4385 处 [n] 实测）

**挂尾形态**：
- 句末引用（[n] 后紧跟 。！？；或段尾）占 **39.0%**；句中引用 2673 处（61%），同样合法——引用位置由句子结构决定，不强制句末。
- 高频引导词：**「认为/指出/提出」**（观点转述）、**「包括/分为/构成」**（列举挂尾）、**「源于/来自/源自」**（概念溯源）。

**可套骨架**：
- 观点转述：`××[n]认为/指出/提出××。`
- 并列列举：`××将××概括为A、B、C与D[30]；从××角度提出其关键要素为××[31]。`
- 概念溯源：`「××」概念源于××的「××」理论，是××的开放场域[5]。`
- 数据挂尾：`××数据因可获取性和结构化程度较高[5]，成为××分析的重要基础资料[6]。`

> 与 `citation-format.md` 的关系：那份管「标注形态规范」（范围式/列举式/禁用混合式），本文件管「引用周边的句子怎么写」。
