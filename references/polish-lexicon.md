# 润色语言词典（Polish Lexicon）

> **本文件由 `scripts/polish_lexicon.py` 基于 118 篇原文（121 万字正文）挖掘生成，2026-10 更新。**
> 每条替换建议都带该刊原文的真实使用次数——不是词典规范，是语料证据。
> 重新生成：`python scripts/polish_lexicon.py --json`（写语料库 `polish_lexicon.json`）。
> 查单个词在该刊怎么用：`python scripts/polish_lexicon.py <词>`（输出真实上下文例句）。

## 使用方式（模式 B 改写时）

1. **先定位问题词**：用 `diagnose_paper.py --brief` 的段落级扫描找到目标段。
2. **再查本词典**：找到口语词 → 看该刊实际用什么书面词（有次数对比）。
3. **最后验证替换**：`python scripts/polish_lexicon.py <候选词>` 看该刊真实例句，确认搭配自然再换。
4. 纪律照旧：字数 ±10%、句均 ≤68、不增饰。

## 2. 程度表达：该刊怎么写「程度」

### 审慎词 vs 强断言词（原文频次）

| 类型 | 词（频次） |
|---|---|
| **审慎/限定**（该刊主流） | 可能 313｜相对 222｜逐步 175｜通常 104｜多数 102｜一般 95｜往往 83｜日益 60 |
| **强断言** | 显著 461｜全面 236｜充分 234｜一定 199｜完全 91｜极大 35｜必然 25｜绝对 17 |

**纪律**：
- 「显著」在该刊 **461 次，是最高频强断言词**——但它的真实用法是**统计口径**（"显著相关/显著影响/显著差异"），不是泛泛的"显著提升"。润色时把无统计支撑的"显著"改为审慎词（有所/一定程度上/相对）。
- 「全面」236 次多与"全面性/全方位"搭配作定语，慎作状语。
- 无数据支撑的判断，该刊用「有所」「一定程度上」「相对」「趋于」（合计 43+158+50 处趋势/弱化表达）。

### 程度句式真实分布（118 篇）

| 类型 | 处数 | 典型句 |
|---|---|---|
| 趋势渐进（日益/逐步/渐趋/持续） | 916 | 「新兴技术持续赋能××发展与人才培养革新」 |
| 多数限定（大多/多数/绝大部分） | 158 | 「传统的策略多数是采用基于规则、统计分析方法」 |
| 显著（统计口径） | 106 | 「语义差异量表与眼动数据之间存在显著相关性与一致性」 |
| 相对比较（相对/较之） | 50 | 「相较于传统的课程体系内容分析，这一流程能够更细粒度地捕捉××」 |
| 审慎弱化（有所/一定程度上） | 43 | 「××有所提升」「一定程度上缓解了××」 |
| 明显（描述口径） | 11 | 「中、美两国院校在××方面也存在明显差异」 |

> 「明显」仅 11 处 vs「显著」106 处——**描述性差异用"明显"，统计结论用"显著"**，不要混。

## 3. 句法特征（次/千字，119 万字统计）

| 句法现象 | 频次 | 润色含义 |
|---|---|---|
| 动态助词「了」 | **2.7/千字**（3225 处） | **67% 的段落一个「了」都没有**——不是禁用，而是「叙述研究过程」时才用；属性/状态陈述尽量不用 |
| 被动「被」 | **0.53/千字**（628 处） | 该刊**少用"被"**——"被广泛应用于"改"广泛应用于"或"得以广泛应用" |
| 动态助词「着」 | 0.37/千字（437 处） | 多出现在"随着"（表伴随），非进行体 |
| 「即/也就是说」解释句 | **0.35/千字**（418 处） | **该刊最常用的解释手段**：术语后用"即"引出内涵，比括号或破折号解释更贴刊风 |
| 「旨在/以期」目的句 | 0.26/千字（316 处） | 目的句标准写法 |
| 「称为/称之为/视为」定义句 | 0.12/千字（140 处） | 下定义标准句式 |
| 被动「由…（来/所）」 | 0.03/千字（36 处） | 极罕见；"由××完成"可用但非主流 |

### 三条由数据得出的润色规则

1. **「了」按用途决定，不按数量硬删**（4379 段实测：含「了」的段 37%、每段中位 0 个、≥3 个的段仅 8.4%）：
   - **叙述过程**（"提取了 343 个主题词""发放了 200 份问卷"）→ 该用就用，符合刊风
   - **陈述属性/状态**（"该系统提升了效率""平台完善了功能"）→ 改"该系统能提升效率"或删去，属该刊 63% 段落的主流写法
   - 段内「了」≥3 个且都是属性陈述 → 是 AI 稿的典型形态，重点改
2. **少用「被」**：0.53/千字。被动优先改无主句、主动句或「得以××」。
3. **解释走「即」**：术语首现写「××（全称，缩写），即××」；418 处"即"句 vs 破折号插入语寥寥，说明"即"是该刊解释首选。

## 4. 与 anti-patterns / style-rules 的分工

| 文件 | 管什么 |
|---|---|
| `anti-patterns.md` | 不能出现什么（AI 味 8 条、红线） |
| `polish-lexicon.md`（本文件） | 换成什么（口语→书面的刊内实证对应词） |
| `style-rules.md` | 量化到什么程度（句均、段长、密度基准） |
| `patterns.md` | 整段怎么写（句式族与骨架） |

改写一句话的四查：anti-patterns（这句犯禁吗）→ polish-lexicon（该换成什么词）→ patterns（这类段该刊什么骨架）→ style-rules（量化达标吗）。
