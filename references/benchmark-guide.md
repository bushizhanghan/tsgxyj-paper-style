# 对标评估（模式 G）

> 把一篇论文放进语料库分布中横向定位：「比多数刊文强/弱在哪儿」。**评估对象是形式与结构完成度，不是学术质量排名**——创新性与研究价值以编辑部与审稿专家判断为准。

## 输出结构（五段）

1. **形式维度对标表**：9 项指标 × 论文值 vs 刊分布（中位/四分位）× 百分位 × 判定
2. **净度**：反模式命中数（0 = 优于全部刊文）
3. **结构**：章节序列、引言占正文比（对照刊单列引言章中位 7.1%）
4. **同主题参照组**（如存在）：与该方向子集（如无障碍/老年 18 篇）的对比
5. **边界声明**（必带）

## 指标与判定规则

| 指标 | 类型 | 判定规则 |
|---|---|---|
| 段长中位 / 句均 / 摘要长度 / 正文字数 | 中性（看是否落在分布主体内） | 偏短（< P25）／居中／偏长（> P75） |
| 引用密度 / 关键词数 / 文献条数 / 图数 / 表数 | 正向（越高越强，极值另注） | ≥75% 分位▲强 ／ 25–75% ≈中 ／ ≤25% ▼弱 |
| 反模式命中 | 反向 | 0 处 = 最优 |

（百分位含义：高于该 % 的刊文。如 88% = 比 88% 的刊文数值更高。）

## 使用

```
python benchmark_paper.py <论文.docx>     # 需与语料库（corpus_stats.json / paragraphs.json）同目录
```

## 解读纪律

- **辨别"弱项"性质**：文献量、引用密度类弱项是**可修补型**（补文献即改善）；段长、句长的"偏短/偏长"是**风格论断**，需结合模式 A 诊断与全篇判断，不单列建议
- **百分位不等于当期命中率**：刊发是选题+质量+版面的综合结果，分布位置只是形式准备度的参考
- **与模式 A 的分工**：模式 A 出「位置→问题→依据→建议」的详细清单；模式 G 出「分布定位 + 强弱概览」——可先 G 后 A：G 定位、A 细化
- 报告必须携带边界声明（工具已内置）
