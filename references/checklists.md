# 投稿前体例自检清单

> 依据：该刊投稿须知（已核实项）+ 刊内 108 篇体例观察。逐项核对，打勾或标「待处理」。

## 题名与署名

- [ ] 题名简洁，能看出对象＋方法/视角；如用副标题，以破折号衔接
- [ ] 作者姓名、单位、邮编按规定列出；署名投稿前定死（录用后不可改）

## 摘要与关键词

- [ ] 中文摘要 200–300 字，报道性、第三人称
- [ ] 摘要无「本文」「分析了」「提出了」字样
- [ ] 摘要含目的—方法—结果（带数字）—结论四要素
- [ ] 关键词 4–5 个；无「研究」「发展」等泛词
- [ ] 英文题名/摘要/关键词与中文一一对应；专业术语前后一致（如无障碍=accessibility）
- [ ] 英文摘要以一般现在时为主，无中式长句直译
- [ ] 英文题名/摘要/关键词与中文对应

## 标题层级

- [ ] 层级用阿拉伯数字「1」「1.1」，左顶格，≤4 层
- [ ] 编号后跟全角空格，标题名不带句号
- [ ] 「结语」独立成节且写短

## 正文

- [ ] 段落以 150–350 字为主体，无 50 字以下碎段
- [ ] 句长以 40–90 字书面长句为主
- [ ] 引用密度大体符合 1.5–4 处/千字（综述段可更高）
- [ ] 「本文」全文 ≤15 次，摘要中为 0
- [ ] 对策/策略条目与前文发现一一对仗

## 图表

- [ ] 引言区无图表
- [ ] 图、表分别独立编号；正文先提及后出现
- [ ] 表格三线表；表题在上、图题在下；均注明资料来源
- [ ] 图黑白打印可辨（不以颜色为唯一区分手段）

## 参考文献

- [ ] GB/T 7714-2015；顺序编码制，按正文首次引用顺序编号
- [ ] 同一文献多次引用使用同一序号
- [ ] 网络文献含引用日期与 URL
- [ ] 只列实引文献，不虚列

## AI 味自查（对照 anti-patterns.md）

- [ ] 无三词同构连排（「×化、×化、×化」）
- [ ] 无「具有重要意义/值得深入探讨」类万能句独立出现
- [ ] 无「大量研究表明」等不带引用的模糊指称
- [ ] 段首无机械「首先/其次/最后」链（对策段用「其一/其二」）
- [ ] 无同义反复句；无形容词通胀（显著/极大/全面无数据支撑）

## 引用真实性自查

- [ ] 每条参考文献可溯源（真实存在于刊物/数据库，核不到的删）
- [ ] 正文引用点与文献内容对应（无装饰性引用）
- [ ] 同一文献全文序号一致；同处多引格式统一
- [ ] 摘要、正文、结论中的数字互相一致（样本量/百分比/系数）

## 投稿材料

- [ ] 全文字数 10000 以上
- [ ] 查重：官方口径 <10%，但**投稿者实操反馈要求总文字复制比 <7%、去除引用文献复制比接近 0**——按 7% 准备更稳
- [ ] AIGC 检测 <10%
- [ ] **参考文献格式**：该刊"十分看重"——按 GB/T 7714 逐条核对（可跑 `verify_refs.py` 三项自动核验）
- [ ] 作者简介（姓名、单位、职称、研究方向、联系方式）
- [ ] 唯一投稿渠道：邮箱 tsgxyj@vip.163.com（该刊无在线投稿系统；随稿附查重报告）
- [ ] 费用：官方声明全免费；个别早期投稿者提及费用记录（与声明冲突）——如遇收费要求，先致电编辑部核实
- [ ] 周期预期：审稿 1–3 个月（主题高度吻合时最快 7 天–1 个月出意见）；见刊排期约半年——结题、毕业用途提前算好提前量

## 提示

- 体例细节随年份可能微调，每年投稿前扫一遍最新一期或官网须知；
- 本清单不含「内容质量」审查（选题价值、方法严谨性另评）。
