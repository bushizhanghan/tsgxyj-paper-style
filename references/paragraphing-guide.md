# 分段操作指南（数据实证）

> 依据：本刊 118 篇正文段落全量统计（4379 段，≥80 字）。分段是"内容节奏"的外化——该刊的分段规律可以直接作为切分/合并的依据。

## 一、该刊分段画像（实测）

| 指标 | 实测值 |
|---|---|
| 段长 | 中位 206 字；主体 130–330 字（剔表格残段后中位 236） |
| **每段句数** | **中位 3 句；2–3 句段 38%、4–6 句段 35%（合计 73%）**；7 句以上仅 15% |
| 长段（≥450 字） | 12.9%——中位 8 句、句均 75 字（多句＋长句叠加，多为综述/方法展开段） |
| 段首模式 | **83% 直接陈述起句**；序号/条款式 12%（对策段）；回指式 2%；衔接词起句仅 2% |
| 结论句位置 | "结果表明/研究显示"类句式 **74% 出现在段中**（非段首段） |
| 一句段 | 极少（碎段多为表格残留与短过渡句——短过渡不独立成段） |
| 句内分句 | 均长 16–21 字（长段与普通段同密度——长主要长在句数） |

## 二、切分规则（何时分段）

按优先级：

1. **论点切换必切**：一段承载一个论点/一个论证步骤。出现"新的观点、新的对象、新的维度"即切
2. **句数复查线**：段内到 **7–8 句**时复查——该刊 7 句以上段仅占 15%，多为综述展开
3. **字数复查线**：超过 **450–500 字**时复查（除综述/方法的长展开段可有例外）
4. **大转折处切**：从"现状"转入"问题"、从"分析"转入"对策"、"分述 A"转入"分述 B"处
5. 切分后每段仍应 ≥2 句（避免切出一句段——该刊不用）

## 三、合并规则（何时合段）

1. **同论点的相邻碎段合并**：两块 <100 字、语义同一（如"背景+背景补充"），合并后 ≤350 字
2. **过渡句不独立成段**：单句过渡并入下段之首或上段之尾
3. **"首先/其次"式平行短段**：若各 <150 字且同属一个论题，合并为"其一……其二……"单段；若分别是独立论点则保持分段（对照该刊对策段的条款式分布）
4. 合并的检验：合完后段首句仍能自然起句、段内不超过 6 句

## 四、段内结构范式（该刊习惯）

1. **起句**：直接陈述（83%）——"XX 是 XX 的 XX。""在 XX 层面，……""XX 方面，……"；**不靠"然而/此外"开场**（衔接词起句仅 2%，衔接靠内容回指）
2. **展开**：2–6 句完成"提出→展开→（如需）收束"；并列信息用分号连接（句内分句 16–21 字）
3. **结论句**：放段首第 1–2 句或置于段中第 2–3 句；"结果表明"类引导语可用可不用（该刊多直接给发现）
4. **收束**：段末自然落在具体判断上，不用"综上所述"式套话收尾（该刊罕见）

## 五、各章节段落形态（与 section-guides 配合）

| 章节 | 典型段式 |
|---|---|
| 引言 | 2–3 句/段；背景一句一段可行（过渡性强）；缺口段稍长 |
| 文献综述 | 4–6 句/段；一条文献线索一段；综述长展开（≥450 字）集中于此 |
| 研究设计 | 3–5 句/段；方法论证、数据、工具各成段 |
| 结果分析 | 2–4 句/段；按发现切段（一个发现一段） |
| 对策建议 | 条款式（"其一……（1）（2）……"）一段一条对策；单条 150–300 字 |
| 结语 | 2–3 段收束，每段 3–4 句 |

## 六、诊断与改写联动

- `diagnose_paper.py` 的段落级扫描会标出：句均偏短段、序数词集中段、**超长段（>450）/碎段（<100）**
- 改写（模式 B）遇到分段问题：先按本指南切/并，再执行词层/句层改写
- 校验口径：改后段落句数分布应向"2–6 句为主"靠拢
