# 改写操作示范与纪律（模式 B）

> 本文件是模式 B（改写）的实操基准。第一条纪律：**逐段判断，不按全篇均值动手**——全篇句均落后（如 52 vs 刊 62），不等于每个段落都要加长；多数段落问题在"词层"（序数词、口语词），不在"句层"。

## 操作流程（五步，第 3 步为 2026-10 新增的润色词层）

1. **先测段**：对被改段落先算三个指标——句均字数、序数/口语词、是否达标。
2. **定干预层级**：
   - 句均 ≥ 50 且序数/口语词 ≥2 → **只做词层调整**（替换序数词、书面化口语词、调衔接）
   - 句均 45–50 → 词层 + 个别句合并
   - 句均 < 45 → 词层 + 句层合并（短分句并长句）
3. **查润色词典**（词层替换的唯一依据）：`references/polish-lexicon.md`
   - 口语词 → 该刊书面词（带刊内次数对比，如「差不多 0 次 → 基本 281 次」）
   - 程度词：无统计支撑的「显著」→ 「有所/一定程度上/相对」（该刊审慎词 43+158+50 处）
   - 句法：「了」用于叙述过程可留、属性陈述删；「被」改主动/「得以」；解释走「即」
   - 拿不准的词先查原文：`python scripts/polish_lexicon.py <词>`（输出该刊真实例句）
4. **守住幅度上限**：改写后字数 ±10% 以内、句均不超过该刊中位 +10%（≈68 字）。
5. **不增饰**：不添加原文没有的概括句、评价语、过渡句——改写是「换表达」，不是「补内容」。

## 示范案例（真实案例·三版对比）

**场景**：某论文 2.2 节段落（431 字，句均 61 字，序数/口语词 6 处）。全篇均句长偏短，但本段句均已达标——属于"词层问题"段落。

| 版本 | 字数 | 句均 | 序数/口语 | 判定 |
|---|---|---|---|---|
| 原文 | 431 | 61 | 6 | 词层待改 |
| ❌ 过度版 | 500（+16%） | 70（超线） | 0 | **不合格**：超幅、增饰 |
| ✅ 最小干预版 | 449（+4%） | 63 | 0 | 合格 |

**过度版的两个错误**（引以为戒）：
1. 把已达标的句长继续拉长（61→70，超过该刊中位 +10% 红线）
2. 增饰——添加了原文没有的概括表述（"构成了需求分化的起点""源于系统能力的边界"）。这些句子读起来"很像论文"，但**是改写者发明的，不是作者写的**。

**最小干预版的实际改动**（8 处词句级替换，全文骨架未动）：

| 原 | 改 |
|---|---|
| 把障碍类型与场景合起来看 | 综合障碍类型与场景来看 |
| 排在首位 | 最为基础 |
| 其次是个性化适配 | 个性化适配紧随其后 |
| 更进一层 | 涉及系统之外的补充 |
| 排在最后 | 则关注使用情境的差异 |
| 各有一套应对 | 均有相应的应对方式 |
| 信息获取通道本就不一样 | 信息获取通道本就不同 |
| 它们合在一起，为判定… | 四类需求共同为…的判定提供了分类基础 |

## 段落类型与干预参考

| 段落类型 | 常见问题 | 干预重点 |
|---|---|---|
| 需求/分类段（排比结构） | 序数词多、句式同构 | 词层：序数词换内容递进（"最为基础/紧随其后/源于…边界"） |
| 综述段 | 句均偏短 | 句层：合并短分句；保持"叙述＋[n]挂尾" |
| 系统描述段 | 短句罗列（"接入层即…。业务层即…。"） | 词层＋轻度句层：合并"即"字句为同句并列 |
| 对策段 | 条款式偏短句 | 保留"其一…（1）（2）"结构，只做衔接调整 |

## 自检（改写完成后）

- [ ] 事实、数字、引用照旧（逐项比对）
- [ ] 字数在 ±10% 内
- [ ] 句均未超过 68 字
- [ ] 无新增的概括句/评价句（对照原文逐句核对"这句是谁说的"）
- [ ] **口语词已按 `polish-lexicon.md` 替换**（该刊 0 次的词必须清掉）
- [ ] **无统计支撑的「显著」已降为审慎词**
- [ ] **属性陈述的「了」「被」已改**（叙述过程可留）
- [ ] 读一遍：是"更像该刊"，不是"更像 AI"
