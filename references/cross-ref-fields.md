# 参考文献交叉引用域操作指南

> 目标：把正文 `[20]` 这样的引用标注设为 Word **交叉引用域**（REF 域）——外观不变（上标 [n]），Ctrl+点击可跳转到文末对应条目，引用与文献表结构化关联。

## 一、为什么用域

- 引用与文献表建立结构化关联（可跳转、可核查）
- 配合脚本可在文献增删后快速重建对应关系
- Word 原生支持（引用 → 交叉引用），无需第三方插件

**诚实说明**：REF 域引用的是书签位置的文本——删除某条文献后，其余条目的编号**不会自动重排**（需要配合重建脚本或手动调整）。它的核心价值是"结构化 + 可跳转 + 可脚本化批量操作"，不是全自动化编号。

## 二、三条路径

### 路径 1：脚本（推荐，本 skill 附带）

```
scripts/build_xref.py     # 纯文本 [n] → REF 域（文末加书签 + 正文建域）
scripts/unfield_refs.py   # REF 域 → 纯文本 [n]（退域，供编辑）
scripts/xref_verify.py    # 转换结果核验（文本零变化 / 配平 / 上标）
```

三个脚本均需 `python-docx`。典型循环见下文"编辑生命周期"。

### 路径 2：Word 手动（单条引用）

1. 文末参考文献条目的 `[n]` 选中 → 插入 → 书签 → 命名 `_Ref20`（添加）
2. 正文 `[20]` 选中 → 引用 → 交叉引用 → 引用类型"书签" → 选 `_Ref20` → 插入
3. 正文引用设为上标（Ctrl+Shift+=）
4. 全文完成后 Ctrl+A → F9 更新域

### 路径 3：不设域

短文档或终稿阶段，纯文本 [n] 也完全可以——域不是必须的。

## 三、编辑生命周期（核心纪律）

```
纯文本态 ──build_xref──▶ 域态（校对/送审/跳转）
   ▲                        │
   └──unfield_refs──────────┘
```

**编辑铁律**（实战教训，逐条遵守）：

1. **只改格式、或只改不含引用的段落 → 什么都不用做**（最安全：别碰域）
2. **要改含引用的段落文字** → 先 `unfield_refs.py` 退域 → 改文字 → `build_xref.py` 重建
3. **`build_xref.py` 只能跑一次**：重复运行会造成域嵌套（域里套域）——修复方法：再 `unfield_refs.py` 退干净 → 单次重建
4. **每次建域后立刻核验**：`xref_verify.py` 四项全过才算成功（文本零变化 / begin=separate=end 配平 / 正文全上标 / 引用均有书签）
5. **运行前必备份**；`PermissionError` = 文件被 WPS/预览占用，关掉后重试（写盘失败 = 文件未动，可放心重跑）

## 四、Word 域基础知识

- 域结构：`begin → instrText（REF _Ref20 \h）→ separate → 缓存显示文本 → end`
- 显示的 `[20]` 是"缓存文本"，按 F9 或打印时刷新
- `\h` 开关 = 生成超链接（Ctrl+点击跳转）
- Alt+F9 可切换"域代码 / 显示结果"视图，肉眼检查域是否完好
- 删除域：选中整个域（含灰色底纹）按 Delete，再手打 [20]

## 五、与增删文献的配合

- **增补文献**（如从 24 条扩到 30 条）：退域 → 文献表加新条目并重排编号 → 正文引用点同步改号 → 重建域 → 核验
- **删除文献**：同上，反向
- 每次重排后必须重跑引用核验（序号连续 / 正文-列表对应 / 混合式检查）——`verify_refs.py` 可复用
